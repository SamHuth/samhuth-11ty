# {{ page.title }}

Is this even worth trying?

<br />

As I was preparing a list of about fifty images for a gallery page, it struck me that I need to attach alt text to each one of them. I'm trying to be more proactive on accessibility standards, so I gave my full attention to writing descriptive content for each image. After writing multiple for a selection of very similar images a thought occurred. This feels awfully similar to prompting an image generator for slightly different results.
And it got me thinking... these alt texts may be good enough for a human to visualise, but could an image generator do the same? Is a recognisable image generated from my alt text a sign of good alt text? Could it analyse my image, write alt text and come to the same result?
